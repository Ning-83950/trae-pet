# 小T · Trae 桌面宠物

一只住在桌面上的 AI 小机器人：会眨眼、会溜达、会说话，能摸头、揍它、投喂，有心情/饱食度/等级养成、成就系统、人格切换、天气播报和 AI 换装。

基于 PyQt5 的无边框透明窗口桌宠，全部资源本地生成，无需联网即可运行（天气和 AI 换装识别除外）。

## 功能一览

**互动**
- 点击身体不同区域有不同反应（摸头、戳肚子、打脸……）
- 连续揍它会触发击倒：三种倒姿随机（侧倒 / 镜像侧倒 / 趴倒），倒地方一段时间自己爬起来
- 拖拽移动、滚轮缩放、双击互动

**养成**
- 心情 / 饱食度 / 经验值 / 等级
- 成就系统（首次击倒、首次换装等）
- 多套人格可切换，不同人格台词风格不同
- 深夜自动进入静默模式，不吵你

**表现**
- 眨眼、走路、跳跃、爱心特效、晕倒冒星星、睡眠 ZZZ
- 三套随机挥拳动作
- 根据本地天气主动搭话（温度 / 下雨提醒）

**AI 换装**
- 菜单里选一张真人/动漫图片，自动识别人脸（OpenCV YuNet + grabCut 抠图），把脸贴到卡通身体上
- 支持分层皮肤（头 + 身体分开缩放贴合）

**可靠性**
- 崩溃日志自动写入 `pet.log`（存档同目录），闪退排查不用猜
- 17 项离屏回归测试（`test_pet.py`），改动前先跑一遍

## 快速开始

```bash
pip install PyQt5
python trae_pet.py
```

或直接双击 `start_pet.bat`。

换装功能额外依赖：

```bash
pip install opencv-python numpy pillow
```

## 操作说明

| 操作 | 效果 |
|---|---|
| 左键点击身体 | 互动（部位不同反应不同） |
| 左键拖拽 | 移动位置 |
| 滚轮 | 缩放 |
| 右键 | 菜单：说话 / 揍揍 / 摸头 / 投喂 / 散步 / 睡眠 / 更多 |

存档保存在 `pet_save.json`，想重置直接删掉它。

## 运行测试

```bash
python test_pet.py
```

覆盖菜单结构、击倒状态机（fall→lie→up）、日常互动、换装错误路径、存档 roundtrip。全部通过退出码为 0。

## 打包免安装版

```bash
pyinstaller --windowed --onedir --add-data "pet_art;pet_art" --name "小T机器人" --clean --noconfirm trae_pet.py
```

产物在 `dist/小T机器人/`，整个目录拷给别人即可运行，无需 Python 环境。

## 目录结构

```
trae_pet.py      # 桌宠本体（单文件，约 2400 行）
test_pet.py      # 离屏回归测试
start_pet.bat    # Windows 一键启动
pet_art/         # 皮肤素材
pyproject.toml   # 依赖声明（uv）
```

## 说明

- 天气功能使用 ip-api.com 定位 + 公开天气接口，仅在你没关网络时生效，失败时自动静默
- 换装的人脸识别在本地完成，图片不会上传
- 崩溃日志 `pet.log` 只记录 traceback，不包含任何隐私数据
