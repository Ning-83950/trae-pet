# 小T · Trae 桌面宠物

一只住在桌面上的 AI 小机器人：会眨眼、会溜达、会说话，能摸头、揍它、投喂，有心情/饱食度/等级养成、成就系统、人格切换、天气播报、AI 换装，还能帮你盯着 Trae 的积分余额。

基于 PyQt5 的无边框透明窗口桌宠，全部资源本地生成，无需联网即可运行（天气、AI 换装识别和积分同步除外）。

> 免安装版下载：[Releases](https://github.com/Ning-83950/trae-pet/releases)

## 功能一览

**互动**
- 点击身体不同区域有不同反应（摸头、戳肚子、打脸……）
- 连续揍它会触发击倒：三种倒姿随机（侧倒 / 镜像侧倒 / 趴倒），倒地方一段时间自己爬起来
- 拖拽移动、滚轮缩放、双击互动
- 悬停时底部浮出搜索框：回车或「网页」用默认浏览器搜索，「Trae」直接唤起本机 Trae IDE 并把问题复制到剪贴板

**Trae 积分监控**
- 启动 9 秒后自动同步一次，之后每 30 分钟同步一次
- 从浏览器（QQ 浏览器 / Chrome / Edge）的 localStorage 里取 `Cloud-IDE-Token`，按 JWT 的 `exp` 取最新一份，再调 `api.trae.cn` 查余额
- 右键菜单「积分面板」看余额、已用、更新时间和各积分包剩余；「立即同步积分」手动刷新
- 余额变动主动播报，低于 500 只提醒一次
- 凭证约 8 小时有效，过期会提示去 trae.cn 刷新，不会静默失败

**养成**
- 心情 / 饱食度 / 经验值 / 等级
- 成就系统（首次击倒、首次换装等）
- 多套人格可切换，不同人格台词风格不同
- 深夜自动进入静默模式，不吵你

**表现**
- 眨眼、走路、跳跃、爱心特效、晕倒冒星星、睡眠 ZZZ
- 三套随机挥拳动作
- 根据本地天气主动搭话（温度 / 下雨提醒）

**AI 换装**
- 菜单里选一张真人/动漫图片，自动识别人脸（OpenCV YuNet + grabCut 抠图），把脸贴到卡通身体上
- 支持分层皮肤（头 + 身体分开缩放贴合）

**可靠性**
- 崩溃日志自动写入 `pet.log`（存档同目录），闪退排查不用猜
- 29 项离屏回归测试（`test_pet.py`），改动前先跑一遍

## 快速开始

```bash
pip install PyQt5
python trae_pet.py
```

或直接双击 `start_pet.bat`。

换装功能额外依赖：

```bash
pip install opencv-python numpy pillow
```

## 操作说明

| 操作 | 效果 |
|---|---|
| 左键点击身体 | 互动（部位不同反应不同） |
| 左键拖拽 | 移动位置 |
| 滚轮 | 缩放 |
| 鼠标悬停 | 底部浮出搜索框（回车 = 浏览器搜索） |
| 输入框右侧「Trae」 | 唤起 Trae IDE，内容复制到剪贴板 |
| 输入框右侧「网页」 | 用默认浏览器搜索 |
| 右键 | 菜单：说点什么 / 揍一拳 / 投喂 / 看看状态 / 积分面板 / 立即同步积分 / 到处走走 / 换装 / 性格 / 退出 |

存档保存在 `pet_save.json`（含最近一次积分数据），想重置直接删掉它。

积分功能需要先在浏览器登录过 trae.cn：小T 只读取浏览器本地存的登录凭证，不上传任何东西。凭证有效期约 8 小时，浏览器访问一次 trae.cn 会自动续期。

## 运行测试

```bash
python test_pet.py
```

覆盖菜单结构、击倒状态机（fall→lie→up）、日常互动、换装错误路径、存档 roundtrip、积分链路（JWT 解析 / 过期判定 / 数据落盘 / 右键入口）和搜索框按钮布局。全部通过退出码为 0。

## 打包免安装版

用仓库里的 spec 打包（已包含素材与图标配置）：

```bash
pyinstaller --noconfirm --clean 小T机器人.spec
```

或手写参数：

```bash
pyinstaller --windowed --onedir --add-data "pet_art;pet_art" --name "小T机器人" --clean --noconfirm trae_pet.py
```

产物在 `dist/小T机器人/`，整个目录拷给别人即可运行，无需 Python 环境。存档与日志写在 exe 同目录。

## 目录结构

```
trae_pet.py        # 桌宠本体（单文件，约 2600 行）
test_pet.py        # 离屏回归测试（29 项）
start_pet.bat      # Windows 一键启动
pet_art/           # 皮肤素材
小T机器人.spec      # PyInstaller 打包配置
pyproject.toml     # 依赖声明（uv）
```

## 说明

- 天气功能使用 ip-api.com 定位 + 公开天气接口，仅在你没关网络时生效，失败时自动静默
- 换装的人脸识别在本地完成，图片不会上传
- 积分同步走 `https://api.trae.cn`，请求头里带浏览器同款 UA（该接口会校验指纹），凭证只在本机内存里用，不落盘、不外发
- 积分凭证过期是常态（8 小时），过期时右键「立即同步积分」会直接说明原因
- 崩溃日志 `pet.log` 只记录 traceback，不包含任何隐私数据
